### Установка

Перед запуском необходимо:

- Установить **Node.js**: https://nodejs.org/
- Установить **Yarn**: https://yarnpkg.com/.
- Скопировать `.env.example` и переименовать его в `.env`, актуализировав значения внутри
- Установить зависимости (`yarn install`)

### Запуск

Для запуска доступны следующие `make` команды:

- `make local` - запустить тесты локально, ход выполнения будет выводиться в консоли, после завершения откроется репорт
- `make local-ui` - запуск с помощью приложения playwright
- `make docker` - запуск в докер контейнере
